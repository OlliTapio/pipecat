- Fixed a user turn staying open after a mute ended, such as `FunctionCallUserMuteStrategy` muting while the user was still speaking. A mute in `LLMUserAggregator` now applies from the next user turn: the turn already open keeps its speech stop and transcripts, and a stop whose start passed unmuted is let through. A turn that ends while muted with a function call pending is written to the context without running the LLM, since the function result runs it.
