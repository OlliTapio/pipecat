- Fixed `LLMUserAggregator` leaving the user turn open when the user stopped speaking while muted (for example by `FunctionCallUserMuteStrategy`). A mute no longer suppresses a `VADUserStoppedSpeakingFrame`, `UserStoppedSpeakingFrame` or `ProposedUserStoppedSpeakingFrame` whose matching start frame got through before the mute. Before, the turn stayed open until the user spoke again, and a function call result waiting for the turn to end never ran the LLM.
