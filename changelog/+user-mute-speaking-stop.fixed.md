- Fixed a user turn left open when the user stopped speaking while muted (for example by `FunctionCallUserMuteStrategy`), which held a function call result's LLM run until the user spoke again. A mute no longer suppresses a `VADUserStoppedSpeakingFrame`, `UserStoppedSpeakingFrame` or `ProposedUserStoppedSpeakingFrame` whose matching start frame got through before the mute, so the turn ends through the normal turn stop. The mute still drops the turn's transcripts, so a stop strategy waiting for one ends the turn at `user_turn_stop_timeout`. With `LLMUserAggregatorParams(vad_analyzer=...)`, muted audio never reaches the VAD, so the stop comes from `audio_idle_timeout`; with `audio_idle_timeout=0` the turn stays open until the user is unmuted.
- Fixed a function call result that arrived while the user was speaking never running the LLM when the end of the user's turn ran no inference of its own: the turn was empty, its inference ran mid-turn, or its end confirmed a speculative response. `LLMAssistantAggregator` now pushes the held context when such a turn ends.
